# SRC7E - D3D Dry-Run Source Binding Review

SRC7E creates a read-only dry-run source binding review for explicit SML / structural-location evidence.

## Context

SRC7A created the explicit SML contract.

SRC7B created the runtime explicit SML source adapter.

SRC7C deployed and proved the runtime source probe.

SRC7D created the explicit SML source-evidence preflight validator.

## Purpose

SRC7E determines whether valid explicit SML source evidence can be bound to a candidate in dry-run mode.

This is source binding only.

It is not production D3D eligibility.
It is not operator-control confirmation.
It is not mutation authorization.

## Strict Boundary

SRC7E is read-only and dry-run only.

SRC7E does not persist records.
SRC7E does not write to Supabase.
SRC7E does not mutate campaigns.
SRC7E does not execute D3D.
SRC7E does not authorize D3D.
SRC7E does not confirm operator control.
SRC7E does not alter score, rank, state, transition, probability, edge, target, gamma/options, or trade signals.

## Doctrine Limitation

A valid source binding may satisfy one source-evidence requirement.

It does not satisfy the full D3D production mutation gate.
