# SRC7D - Explicit SML Source-Evidence Preflight Validator

SRC7D creates the read-only explicit SML source-evidence preflight validator.

## Context

SRC7A created the explicit SML / structural-location evidence contract.

SRC7B created the read-only runtime adapter design.

SRC7C deployed and proved the runtime adapter probe.

## Purpose

SRC7D determines whether supplied explicit SML / structural-location records satisfy the source-evidence requirement.

This is source-evidence validation only.

It is not D3D authorization.

## Strict Boundary

SRC7D is read-only.

SRC7D does not persist records.
SRC7D does not write to Supabase.
SRC7D does not mutate campaigns.
SRC7D does not execute D3D.
SRC7D does not authorize D3D.
SRC7D does not confirm operator control.
SRC7D does not alter score, rank, state, transition, probability, edge, target, gamma/options, or trade signals.

## Doctrine Limitation

A valid explicit SML record may satisfy the structural source-evidence requirement.

It does not, by itself, confirm operator control.
It does not, by itself, make a campaign production-eligible.
It does not authorize mutation.
It does not bypass D3D.
